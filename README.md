## Acerca de FridaMusic

**FridaMusic** es una aplicación de música para Android centrada en una experiencia rápida, visual y flexible. Combina reproducción local, descubrimiento musical, letras, estadísticas de escucha y herramientas para compartir música dentro de una interfaz moderna basada en Material 3.

El proyecto forma parte del ecosistema de **Frida Labs** y continúa en desarrollo activo.

---

## ✨ Características

- 🎵 **Biblioteca local** para organizar y reproducir música almacenada en el dispositivo.
- 🔎 **Búsqueda musical** de canciones, artistas, álbumes, videos y playlists.
- 📚 **Biblioteca personalizada** con favoritos, álbumes, artistas y listas.
- 🎧 **Reproductor completo** con cola, autoplay y controles multimedia de Android.
- 📝 **Letras sincronizadas** y experiencia tipo karaoke cuando el contenido compatible está disponible.
- 🎤 **Reconocimiento de música** mediante el micrófono del dispositivo.
- 🔀 **Aleatorio global** para descubrir y reproducir contenido desde distintas fuentes compatibles.
- 📊 **FridaMusic Recap** semanal, mensual y anual.
- 📤 **Compartir música** mediante enlaces, códigos QR y tarjetas visuales.
- 📱 **Tarjetas para redes sociales** con diferentes estilos visuales.
- 🔔 **Notificaciones y recomendaciones** relacionadas con la actividad musical.
- 💾 **Copia de seguridad y restauración** de datos compatibles.
- 🔄 **Actualizaciones mediante Google Play** en las distribuciones compatibles.
- 🎨 **Temas claro, oscuro y del sistema**, junto con opciones de personalización visual.
- ⚙️ **Temporizador, ecualizador, crossfade, gapless** y otros ajustes de reproducción.
- ⚡ **Optimización continua de rendimiento y estabilidad**, incluida la gestión de bibliotecas locales grandes.

## 📊 FridaMusic Recap

FridaMusic puede generar resúmenes de tu actividad musical para ayudarte a entender mejor cómo escuchas música.

Los Recaps están disponibles en periodos:

- **Semanal**
- **Mensual**
- **Anual**

Según los datos disponibles, pueden mostrar tiempo de escucha, reproducciones, canciones, artistas, álbumes y otros elementos destacados. Los Recaps también pueden compartirse mediante una imagen generada por la aplicación.

## 🧰 Compilación del código legado

> [!WARNING]
> Las siguientes instrucciones corresponden únicamente al código fuente legado disponible públicamente. No representan la arquitectura ni el proceso de compilación de las versiones modernas de FridaMusic.

### Requisitos

- Android Studio, preferentemente una versión estable reciente compatible con el proyecto legado
- JDK 17+
- Android SDK configurado

### Clonar el repositorio

```bash
git clone https://github.com/jagrdev-MX/FridaMusicOF.git
cd FridaMusicOF
```

### Compilar APK

```bash
# Debug
./gradlew assembleDebug

# Release
./gradlew assembleRelease
```

Los artefactos generados por el proyecto legado se encuentran dentro de los directorios de salida de Gradle correspondientes.
